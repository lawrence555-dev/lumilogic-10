## 🌟 專案特色

### 1. 🌲 月份章節地圖 (Monthly World)
進入一個充滿日式極簡風格的冒險世界，而非傳統的關卡列表。
- **生活化結構**: 採用「月份」作為章節單位（如：森林啟蒙、海洋探險）。
- **有機路徑**: 動態呼吸的虛線路徑，引導你的學習旅程。
- **自動存檔**: 內建進度追蹤，所有成就與獎勵皆永久保存。

### 2. 🧊 Chapter 1: 空間推理 (Spatial Reasoning)
第一個月的核心挑戰 —— 透過 3D 視角解謎。
- **3D 互動**: 旋轉懸浮的木質積木，尋找正確的對齊角度。
- **即時回饋**: 透過 "冷/熱" 視覺提示（邊框顏色與發光強度）引導你找到目標。
- **零文字教學**: 直覺的自動演示與手勢提示，讓遊戲玩法一目瞭然。

### 3. ⚖️ Chapter 2: 具象數感 (Number Sense)
第二個月的核心挑戰 —— 結合物理模擬的直覺數學。
- **真實物理**: 整合 Cannon.js 引擎，每一顆松果都擁有真實的質量與碰撞體積。
- **無縫互動**: 獨家的 Ray-Plane 演算法，讓拖曳操作如磁鐵般精準吸附，消除 3D 空間的視差。
- **隱形教學**: 沒有數學公式，只有直覺的天平與重量，讓孩子自然體會「守恆」與「加法」的概念。

### 4. 📅 月份集點卡 (Monthly Rituals)
讓學習成為習慣的儀式感設計。
- **每日任務**: 每天隨機抽取 2-3 個「微挑戰」，完成即可蓋章。
- **實體感印章**: 咚一聲的物理音效，滿足孩子對「完成」的渴望。
- **Lumi 小屋**: 收集印章解鎖家具，裝飾屬於自己的數位秘密基地。
- **無縫導航**: 經過嚴格測試的流暢翻頁邏輯，確保最佳的使用者體驗。

## 🛠️ 技術堆疊

- **框架**: [Next.js 14](https://nextjs.org/) (App Router)
- **語言**: TypeScript
- **3D 渲染**: @react-three/fiber, @react-three/drei
- **樣式**: Tailwind CSS
- **動畫**: Framer Motion
- **圖標**: Phosphor Icons

## 🚀 快速開始

1.  **安裝依賴**:
    ```bash
    npm install
    ```

2.  **啟動開發伺服器**:
    ```bash
    npm run dev
    ```

3.  **開啟瀏覽器**:
    前往 [http://localhost:3000](http://localhost:3000) 開始冒險！
